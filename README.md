# Cacluladora de Endfield
O objetivo é de ter todas as formulas prontas, assim pode só passar as variáveis e já ter todos os números calculados.

## Modo de uso
Execute `./calculadora` para rodar a cacluladora.


_Por mais que eu vou ir atualizando com o tempo,_ você pode utulizar `./adicionar` para adicionar novos equipamentos e/ou armas para a base de dados.

## Coisas

`((OpATK + WATK) * ATK% + fixed + extras) * stat_bonus * ∑~`
`stat_bonus = main * 0.005 + secondary * 0.002`
`total / (6.5 * n_s) + (10 * n_c) * 100 = UGE`
